# SH2ZAM overview artwork

`sh2zam-gainz.webp` is a 512×512 web-sized version of the Saturn / turquoise GAINZ image supplied by the repository maintainer for this overview and interactive exhibit. It is kept separate from the inherited upstream SH4ZAM logos. Sega and Sega Saturn marks are not claims of endorsement.
