Without SH2ZAM · one fixed-point row
// Bounds qualified for this matrix.
int64_t sum =
    (int64_t)row[0] * x
  + (int64_t)row[1] * y
  + (int64_t)row[2] * z;
// SH-2 arithmetic shift floors once.
out = (int32_t)((sum >> 16) + row[3]);

With SH2ZAM · optional native MAC.L
sh2z_mesh_view_t mesh;
sh2z_transform_plan_t plan;

// Once for an immutable mesh:
if (!sh2z_mesh_view_init(&mesh, vertices, count))
    return false;

// Each new matrix:
if (!sh2z_transform_plan_init(&plan, &mesh, &matrix))
    return false;
return sh2z_transform_plan_execute_mac(
    out, &plan, 0, count);
API and contracts ↗


MAC.L is an optional experimental API. It uses native accumulation when bounds qualify and SR.S is clear; otherwise it uses the prepared fallback.




Results & measurement details

Every implementation receives the same quantized vertices and matrices. Costs are medians across 21 poses; matrix qualification is included once per whole mesh. Mesh scanning and input conversion happen once, outside the measured transform.
