Technical notes

Both kernels run as WebAssembly with shared geometry and rendering. These are browser timings, not Saturn benchmarks.

The reference uses a float32 affine transform. SH2ZAM uses saturating Q16.16 arithmetic and wider intermediates. Identical raw Q16 inputs are converted once for the float path; matrix setup uses the same 16-bit angles.

Live timings update every 500 ms using a rolling median of five samples, each averaging 64 transforms. Drawing and matrix setup are excluded. Capture benchmark holds a result for export; playing the scene resumes live timings. Capture pauses the loop, warms both kernels, then takes 21 samples of 64 batch calls each, alternating measurement order. The displayed time is the median per batch, including the JS-to-WASM call. Browser timing resolution, JIT, power state and other tabs can affect results. Export includes the sample distributions and WASM hash.

Use the reveal slider or drag the center handle. Scrubbing pauses animation. Reduced-motion preferences start the scene paused. Changing scene or detail invalidates old timings. The visual projection is shared JavaScript, not SH2ZAM’s integer screen-coordinate projection API.
